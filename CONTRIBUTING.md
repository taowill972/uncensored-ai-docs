# Guide de Contribution

Merci de votre intérêt pour contribuer à uncensored-ai-docs !

## Comment contribuer

### Signaler un bug

1. Vérifiez que le bug n'a pas déjà été signalé dans les [Issues](https://github.com/taowill972/uncensored-ai-docs/issues)
2. Créez une nouvelle issue avec :
   - Un titre descriptif
   - Les étapes pour reproduire le bug
   - Le comportement attendu vs le comportement actuel
   - Votre environnement (OS, version Python, etc.)

### Proposer une amélioration

1. Ouvrez une issue pour discuter de votre idée
2. Attendez les retours avant de commencer le développement
3. Créez une Pull Request en suivant les guidelines ci-dessous

### Soumettre une Pull Request

1. **Fork** le projet
2. **Créez une branche** : `git checkout -b feature/ma-nouvelle-fonctionnalite`
3. **Commitez vos changements** : `git commit -m 'Add: nouvelle fonctionnalité'`
4. **Pushez vers la branche** : `git push origin feature/ma-nouvelle-fonctionnalite`
5. **Ouvrez une Pull Request**

## Standards de code

### Python
- Suivez [PEP 8](https://pep8.org/)
- Ajoutez des docstrings pour les fonctions et classes
- Incluez des type hints quand possible

### Documentation
- Utilisez le Markdown pour tous les fichiers de documentation
- Vérifiez l'orthographe avant de commiter
- Incluez des exemples de code fonctionnels

### Commits
Utilisez des messages de commit clairs :
- `Add: nouvelle fonctionnalité`
- `Fix: correction de bug`
- `Update: mise à jour de documentation`
- `Refactor: refactorisation de code`

## Code de Conduite

Soyez respectueux, inclusif et constructif dans toutes vos interactions.

## Questions ?

N'hésitez pas à ouvrir une issue avec le label `question`.
